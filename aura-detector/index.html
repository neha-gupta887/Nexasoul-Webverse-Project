01 • THE EXPERIMENT

A Creative AI-Driven Personality Lab

Created for the NexaSoul Web Development Foundation Bootcamp at Chandigarh University.

NexaSoul Bootcamp Initiative

Frontend × Full Stack Club • Chandigarh University

This web application is the interactive reference project developed during the NexaSoul Web Development Foundation Bootcamp.

Phase 1

AI Assisted Development

Students learn to construct clean semantic HTML5 markup, responsive CSS architectures, and JavaScript logic using prompt engineering and AI pair programming.

Phase 2

UI/UX Hackathon

Participants take this solid foundation and push their creative limits to design competition-grade, memorable digital experiences with custom animations and aesthetics.

Core Engineering Principles

  • ✦
    Zero Heavy Dependencies

    Pure vanilla HTML5, CSS3, and JavaScript running at 60 FPS.

  • ✦
    Client-Side Graphics Engine

    Native HTML5 Canvas rendering for instant downloadable social cards.

  • ✦
    Accessible & Keyboard Friendly

    Full keyboard navigation support, high-contrast states, and ARIA labels.
